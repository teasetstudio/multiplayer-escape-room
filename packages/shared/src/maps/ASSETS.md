# Original geometric assets

The Stone Hall map layout, `assets/stone-tiles.svg`, and the geometric visual designs generated in `IsometricMap.ts`, `PlayerEntity.ts`, and `MapPreview.tsx` were created for this project. No downloaded artwork, font files, sprite packs, or third-party textures are included.

These original **visual assets and map layout** are dedicated to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). They may be modified and redistributed, including commercially, without attribution. This dedication covers the artwork/layout, not third-party dependencies or a new blanket license for the application's source code.

The SVG is a 192 × 32, three-column atlas for Tiled. Runtime floors use the same stone palette and 64 × 32 diamond geometry; wall/prop shapes and 32 × 34 character cloak textures are generated locally by Phaser. No external asset requests are necessary.
